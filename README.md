# C&C

An original fantasy tabletop-RPG-inspired browser game: pick a class, roll the dice, explore dungeons and collect loot.

## Play

Open `index.html` in any modern browser. No build step or install needed.

## Status

Early development. The game is also published as a Claude artifact; this repo keeps the source and its history.

## Notes

All names, art, and rules are original to this project.
